# Support

This repository is a learning project. It does not provide production support for Microsoft Azure, Terraform, or the AzureRM provider.

Before opening an issue:

1. Read the main [README](README.md).
2. Run `bash scripts/check-repository.sh`.
3. Run `terraform fmt -check -recursive`.
4. Include the Terraform version, AzureRM provider version, command, and complete sanitized error.
5. Remove credentials, IDs, state data, private addresses, and organization information.

For Azure product support, use the official Microsoft support channels. For Terraform provider defects, use the provider's official issue process.
