# Security

Landing-zone security combines preventive, detective, and responsive controls.

## Platform baseline

- Secure privileged identity and emergency access.
- Reduce public exposure.
- Use private connectivity where requirements justify it.
- Enable appropriate Microsoft Defender for Cloud plans after cost and ownership review.
- Centralize security findings and define who responds.
- Protect secrets and certificates in Key Vault.
- Send required logs to approved destinations.
- Define incident response and evidence retention.

## Shared responsibility

The platform team protects the shared foundation. Workload teams still own secure application design, patching, data protection, secrets, and application recovery.
