# Lab 08: Policy Remediation and Exemption

## Goal

Move beyond policy assignment and practice the operational lifecycle.

## Procedure

1. Select a safe built-in audit policy.
2. Assign it at the lab subscription.
3. Identify a non-compliant test resource.
4. Record the compliance reason.
5. If the policy supports remediation, confirm the remediation identity and required role.
6. Run remediation and verify the resource change.
7. Create a time-limited exemption only for a documented test case.
8. Record owner, justification, mitigation, category, and expiry.
9. Remove the exemption and test resource.

## Evidence

- Assignment scope and parameters
- Before and after compliance result
- Remediation task result
- Exemption metadata and expiry
- Cleanup result
